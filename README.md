# VERA

### متجر أزياء نسائية — أناقة هادئة بتفاصيل معاصرة

<div dir="rtl">

**VERA** هي تجربة متجر إلكتروني للأزياء النسائية، تجمع بين البساطة الراقية، الهوية البصرية الدافئة، وتجربة تصفح واضحة ومريحة.

صُمم المشروع ليقدّم واجهة عربية أنيقة لعرض القطع، قراءة تفاصيلها، واختيار المقاس قبل إرسال طلب الشراء.

</div>

---

## ✨ لمحة عن المشروع

- تصميم بصري مستوحى من هوية VERA وشعارها.
- واجهة عربية RTL مع دعم واضح للغة الإنجليزية في العلامة التجارية.
- صفحات منظمة للواجهة الرئيسية، المنتجات، وتفاصيل المنتج.
- تجربة متجاوبة تعمل بسلاسة على الشاشات الكبيرة والصغيرة.
- اهتمام بالتباين، التركيز عبر لوحة المفاتيح، والتنقل الدلالي.
- أسلوب بصري هادئ يعتمد على درجات الكتان، الورق، التاوب، والأسود.

تعتمد VERA على لوحة ألوان مستوحاة من الشعار:

## 🧭 أقسام التجربة

- **الواجهة الرئيسية:** تعريف بالعلامة وأبرز القطع.
- **مجموعة المنتجات:** عرض القطع مع الاسم، الوصف المختصر، والسعر.
- **صفحة تفاصيل المنتج:** صورة المنتج، الوصف، المقاسات، اللون، والمواصفات.
- **خطوات الطلب:** شرح مبسط لمسار اختيار القطعة وإتمام الطلب.
- **قسم عن VERA:** قصة العلامة وروحها التصميمية.

## 🛠️ التقنيات والمبادئ

- HTML دلالي
- CSS حديث ومتجاوب
- تخطيط CSS Grid و Flexbox
- دعم RTL للغة العربية
- تصميم Mobile-first
- خصائص CSS المخصصة لإدارة الهوية البصرية
- تحسينات الوصول، مثل `:focus-visible`، رابط التخطي، وتسميات النماذج
- احترام إعدادات `prefers-reduced-motion`

## 📁 تنظيم مقترح

```text
.
├── index.html          # الصفحة الرئيسية
├── products/           # صفحات المنتجات
├── styles/             # ملفات التنسيق والهوية البصرية

└── README.md           # توثيق المشروع
```

## 🚀 تشغيل المشروع

بما أن المشروع يعتمد على HTML وCSS، يمكن فتح الصفحة الرئيسية مباشرة في المتصفح أو تشغيل خادم محلي بسيط:

```bash
python3 -m http.server 8000
```

ثم افتح:

```text
http://localhost:8000
```
