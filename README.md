# VERA

موقع VERA التجريبي لمتجر ملابس نسائية.

## تشغيل الموقع مجاناً

1. افتحي **Settings → Pages** في مستودع GitHub.
2. اختاري **Deploy from a branch** ثم `main` و`/ (root)` واضغطي Save.
3. سيكون الموقع متاحاً على: `https://vera-no0.github.io/vera/`

صور المنتجات المستخدمة في الموقع هي:
- `images/terracotta-set.jpg`
- `images/chocolate-tunic.jpg`

إذا لم تظهر الصور، ضعي صور المنتجات داخل مجلد `images` بنفس الاسمين أعلاه. لتعديل الأسعار أو المقاسات، افتحي `index.html` وعدّلي نصوص بطاقات المنتجات. الطلبات حالياً تتم عبر Instagram لأن رقم WhatsApp لم يُ provided.
